# What happens when the dashboard is uploaded

1. **Understand the project.** Read the README and the code, run it, load its own example data, and walk every page and chart. I will write one plain language summary: who uses it, what question it answers, where the numbers come from, which files compute results (protected), and how results are displayed and exported.
2. **Suggest ideas**, in two lists: look (palette, layout, typography, charts, loading screen, motion) and customization (what users could tune), each with effort, risk and what it needs from you.
3. **We talk.** You choose. Nothing is changed before that.
4. **Then work on a branch**, with the checks in `port_kit/tools/` run and reported, and nothing scientific changed.

Questions to have ready: who uses it and for how long per session, whether there is a brand or logo to keep, which languages and exports must keep working, and whether there is a sample data file.
